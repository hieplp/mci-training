# mci-training

MCI training challenge — Software Developer Intern.

## Task 1 — `mci-core`

Core library adding two large numbers represented as strings, using the
elementary-school column-addition algorithm.

See [mci-core/README.md](mci-core/README.md) for build/test/usage instructions.

## Task 2 — `mci-web`

Spring Boot + Thymeleaf web app that reuses `mci-core` (Gradle composite
build) and shows the column-addition progress on the page.

See [mci-web/README.md](mci-web/README.md) for run/test instructions.
